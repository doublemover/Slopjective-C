# Security policy

Use [GitHub private vulnerability reporting](https://github.com/doublemover/Slopjective-C/security/advisories/new)
to report a suspected vulnerability in Slopjective-C or its Linux SDK. Include
the release version or source commit, the host architecture, and the affected
component. If you have an SDK archive, include its SHA-256 digest from
`linux-release.json`. Keep sensitive details in the private report.

The [Linux release guide](docs/releases/linux.md) lists the supported
distributions for preview qualification and explains how to verify downloads.
