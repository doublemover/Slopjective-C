# Site source policy

`site/index.md` is generated output from checked-in source.
Manual edits are unsupported.

- Content: `site/src/index.body.md`.
- Contract and front matter: `site/src/index.contract.json`.
- Regenerate: `python -m scripts.build_site_index`.
- Check drift: `python -m scripts.build_site_index --check`.

These are maintainer generation commands. Readers use the installed `objc3c`
and `objc3c-build` tools described by the getting-started tutorial.
Feature claims follow `schemas/objc3-language-capabilities.json` and its generated
reference, `docs/support/clang_foundation_capabilities.json`.

Update source, regenerate, and commit both source and generated bytes. CI checks
site drift, current commands and navigation through the onboarding guard.
The site is a curated overview; specification design does not imply implemented
compiler support. Keep reserved public async/actors explicit.
