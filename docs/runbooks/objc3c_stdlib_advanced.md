# Native concurrency library

`objc3.concurrency` exposes the shared task/frame, group, cancellation, executor and actor runtime ABI. The C++ coroutine adapter remains an explicit header include. Native Objective-C async, public structured-spawn recognition, compiler isolation, Sendable and strict-system helpers remain required work.

See the [standard-library guide](../../stdlib/README.md) for imports, ownership, linking and the executable integration gate, and the [Linux roadmap](../roadmap/linux_forward_development.md) for the complete implementation sequence.
