# Native core library

Core discovery and revision constants, native Optional/Result/error helpers, UTF-8 text and typed collections are available through canonical `objc3.*` imports. Typed key paths remain a compiler/library milestone. Do not use historical fake scalar key-path helpers as evidence.

See the [standard-library guide](../../stdlib/README.md) for imports, ownership, linking and the executable integration gate, and the [Linux roadmap](../roadmap/linux_forward_development.md) for the complete implementation sequence.
