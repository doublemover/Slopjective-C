# Manual frame factories and callable environment ownership

Current execution checkpoint: the maintained native frontend replay, identity and
consumer controls pass in the ABI 24 development embedding. See the
[2.110 consolidation](linux_publication_and_byte_ranges.md). Source-free package
execution, wider matrices and installed SDK qualification remain pending.

Concurrency source 2.109 admits manual producers of the validated physical
`objc3_async_frame` carrier as asynchronous work. C/Objective-C Block/function
parameters and C++ callable objects use the same admission. C++ function pointers
returning task carriers also retain their promise contract. Global lookup permits
C linkage contexts; namespace lookalikes, malformed carriers and scalar factories
do not acquire asynchronous admission. Function designators transport their
ordinary decayed address. Existing strict Sendable/capture checks still apply.

The C++ spawn wrapper stores the callable at a stable address before invocation.
Block values receive an explicit heap copy under ARC and MRC. Inner-frame
teardown happens before releasing that environment, including failed starts,
result-type rejection and exceptions. Null Block/function work rejects before
invocation. This permits manual frames to borrow fields in the callable itself.

`with_task_group` acquires callable ownership in its ordinary creation call and
passes the owned storage to a private scope coroutine. Acquisition therefore
precedes initial suspension and the caller's return. The callback remains owned
through complete structured-scope quiescence, including cancellation and unused
lazy tasks. The physical task/frame service ABI and extension ABI 24 do not change.

Eighteen new C17/C++20/C++23 ARC/MRC source/PCH commands pass, along with twelve
existing concurrent-capture controls. Two focused native configurations pass at
C++20/MRC/O0 and C++23/ARC/O2, thirty scenarios each: four spawn routes with
move-only functors, mutable lambda values, manual Blocks and function pointers;
ordinary task function factories; unused/normal/cancelled lazy group callbacks;
result mismatch, failed start, throwing/malformed producers and null callables.
Manual frame resume and destruction both inspect borrowed closure fields and
exact owner counts. Four package-source modes pass; the package fixture publishes
and instantiates generic manual factories and ordinary task function factories.

The complete C++20/MRC/O0/source and C++23/ARC/O2/PCH spawn configurations
also pass all eleven commands, including callback cleanup and scope quiescence.
Matching frontend execution is in progress.
Source-free package execution, wider sanitizer matrices and final SDK delivery
remain pending. Other capture forms and abstract group-library contracts retain
their own remaining implementation obligations.
