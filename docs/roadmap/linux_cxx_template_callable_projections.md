# Template callable projections on Linux

Source **2.75** extends the complete template publication boundary to canonical
effectful function specializations, callback alias and variable templates, and
dependent typed errors. Existing exact argument, body, ownership, runtime/header
and provider-owned non-inline symbol contracts apply throughout these forms.

The capability `objc3.cxx-template-callable-projections.v1` binds effectful template
owners and explicit namespace specializations. Discovery walks the same published
definitions and authored specialization sets used by runtime contracts. The codec
and module contract reject missing capabilities or incompatible owner kinds with
`O3IFC084`. Alias and variable templates extract native contracts from their
underlying declarations, preserving physical task/frame entry ABI.

qualifiers consistently with canonical error value types; namespace-call spelling
