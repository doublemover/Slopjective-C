# Nested class templates in concrete records

contracts preserve private aliases, storage, defaults, constraints, methods,
member templates, virtual dispatch and source-free consumer instantiation.
Instantiated descendants retain native template mangling and create no
independent interface rows or concrete specialization asm labels.

`objc3.cxx-concrete-nested-templates.v1` is required with concrete-member, class
and nested-template capabilities. Unknown or inconsistent contracts reject.

source, reprint and import. Partial/explicit specializations, detached pattern
definitions, unions, template-template parameters and effectful bodies remain
