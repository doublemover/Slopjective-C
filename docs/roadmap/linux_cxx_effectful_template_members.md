# Effectful template members on Linux

Source **2.74** publishes canonical async/frame and checked-error member function
templates in concrete/generic records, plus ordinary generic class methods.
Complete owners bind checked callable types, heads and definitions. Capability
discovery follows the complete owner into its nested bodies and runtime uses.

The capability `objc3.cxx-effectful-template-members.v1` binds the projection to
class-template or concrete member-template owners. Missing or inconsistent metadata
is rejected with `O3IFC083`. Namespace function-template effects retain their own
capability and are classified by declaration kind.
