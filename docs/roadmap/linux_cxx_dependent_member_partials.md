# Dependent member partial specializations on Linux

Source **2.70** publishes constrained nested class and member variable partial
specializations under dependent record parents. Complete owners bind the exact
definition set, outer heads, argument patterns, constraints, initialization and
bodies. Native replay preserves each outer template head and consumer import
installs authored partials before comparing parent identities.

The capability `objc3.cxx-dependent-member-partials.v1` binds the projection to
complete class-template or concrete member-template owners. Missing or inconsistent
metadata is rejected with `O3IFC079`. Class layout/lifetimes, primary fallback,
constrained non-type selection, shared storage and independent TLS retain native
C++ behavior. Provider source is removed before consumer compilation.

records the emitter suite, sixteen focused native importer tests, all thirty tests
in the native import family, alias ABI code generation, 72 tooling tests and
